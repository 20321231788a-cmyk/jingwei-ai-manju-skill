# 漫剧2 制作工作台

由用户提供的「制作看板与提交脚本源码-20261103-010544.zip」适配。工作区根目录双击「启动制作看板.cmd」，地址 http://127.0.0.1:8766 。依赖 Python、requests；混剪导出使用系统 ffmpeg，缺失时可安装 requirements.txt 中的 imageio-ffmpeg。

直接读取项目的制作数据.json，不生成第二套创作计划。支持分镜审核、完整提示词复制、视频版本预览、混剪与导出、提交接口/内存密钥、首次提交/重提自动队列。未批准或资料不齐的镜头不可付费提交。

上游可逐批切换，任务冻结原接口查询下载。当前适配 RB v1、SparkCine、Wan3买家协议及用户插件的豆包画布Seedance2.0协议；SparkCine支持图片与MP4动作/运镜参考，分别冻结素材用途和编号，未实现视频参考的接口不能登记此类任务。其他协议需要适配器。模型和时长由所选上游实际支持情况决定，不自动换模型或将12–15秒/4–6秒改为20秒拼段。用户明确授权后才运行付费请求。

自动化入口为 submit.py，默认仅预览；--execute 才登记付费任务。详细工作流见 ../../.agents/skills/h3-storyboard-director/references/delivery.md 。移植时复用原 Regenerator、RBClient 与调度锁，把首次提交统一接入同一队列；原压缩包针对旧项目的批次工人、固定110请求和旧计划配置未作为第二套执行入口，避免重复提交。

本机服务仅监听127.0.0.1，保留同源与令牌校验。密钥不入日志/JSON/浏览器持久存储。关闭网页不会停止后台；重启服务需重输对应接口密钥。运行快照在 制作资料/制作看板，视频在各剧集 生成视频/看板重提。不要启动多个端口的副本处理同一工作区。

现行任务按分镜显示最新提交，较早版本归入提交历史；重新提交后按最新任务刷新状态和下载进度。素材始终按分镜归组选版本，已选入时间轴的版本不会被新下载替换。

双击入口默认进入原分镜头看板。在原标题、时长、拍法概述、场景、动作、摄影、H3中文镜头、对白、声音和接点位置点击文字即可编辑；每镜保留保存、提交/重提、同步请求和还原按钮。不再另设表单编辑页或右侧常驻视频预览，视频历史仅在点击“播放版本”时打开。切换镜头保留未保存输入，关闭网页前提醒；不同窗口修改同一镜头提示冲突并保留当前输入。接口配置与只读连接测试保留。

左侧先选择作品，再查看本剧剧集。任务统计、现行任务与提交历史按所选作品筛选，范围可进一步缩至当前集；EP、SP、OP均显示正式编号。切换作品会保留各剧集的剪辑草稿及上次选择，未保存的中文编辑会阻止切换。页面地址保留作品、剧集和视图，刷新可恢复；这些界面偏好不包含密钥，也不更改生成队列或提交快照。

点击“保存中文”将完整编辑值写入该镜头的 `editor_draft.values`（中文镜头全文在 `chinese_description`），状态为 `pending_sync`；已提交提示词与历史任务保持原样。此镜暂时禁止提交，其余已同步镜头仍可操作。点击“复制提示词同步请求”，粘贴回当前聊天，由助手读取原始制作数据中的草稿，同步中文字段、中文镜头、英文六段正文、对白、时长、切点及素材编号，统一检查连续性并更新只读看板后清除 `editor_draft`。不要只删标记而不更新提示词。同步完成后刷新工作台，再确认本次付费提交。后台刷新不会替换正在编辑的文字或正在播放的历史版本。

用户已于2026年11月16日移除失效的豆包临时渠道，已保存的接口配置已删除，以下说明仅供历史任务对照。豆包画布使用`doubao-canvas-v1`，从用户提供的奇哥1.0.18插件提取并适配到本队列，直接访问豆包，不依赖53188主程序；仅接受已编写的Seedance2.0中文15秒、16:9稿与1—9张原图。制作数据以`active_model: seedance2`、`seedance_groups`维护，Wan3原分支保留；图片绑定及完整提示词按请求冻结。画布节点和请求ID在生成POST前落盘，超时后只核对原节点。接口仅设置比例和时长，画板上的像素尺寸是制作目标，不表示接口锁定了输出清晰度；实际视频以下载后的探测为准。

会话只保存在服务内存。`/api/profiles`可显式传`open_session: true`初始化单一正常游客会话；有已发送任务后不允许用此选项换身份。本人已登录Cookie可通过密钥输入或指定环境变量传入，只发送给豆包域名，不写JSON或日志；重启需恢复原会话。禁用原插件的每任务换游客、随机身份、无限重试和解水印分支。正常权限或额度不足时停止新提交，保留已受理任务的查询下载。豆包通道按该会话计数，不占用其他接口遗留任务的并发。
