# 项目专属技能

## 创建与续作

每部正式作品在工作区根目录使用独立项目文件夹，并建立 `AGENTS.md`、`.agents/skills/<项目技能名>/SKILL.md` 及本剧独立的 `<作品名>/启动制作看板.cmd`。前两者只负责入口与保存本作品长期有效的创作差异；`<作品名>/启动制作看板.cmd` 指向工作区共享的 `tools/studio/launch.py --project "<作品名>"`，实现“一剧一看板”，将该剧的扫描、队列快照、上游配置、剪辑方案与导出隔离保存在 `<作品名>/制作资料/制作看板/`，避免多部作品混杂与反复全库加载。收到原件后由Agent直接建立、填充，不增加启动审批。没有实际作品时只保留创建机制，不预建仙侠、悬疑等空项目。

可用主技能的 `scripts/create_project_skill.py --project "作品名" --genre "题材" --director "导演拍法" --style "画风预设或自定义描述"` 创建入口，脚本会同时自动创建 `<作品名>/启动制作看板.cmd`（不存在时补建，已有自定义启动脚本时不覆盖）。题材与拍法可暂不传，读完原件后直接补入专属技能；**若创建新项目时用户未指定画风（未传 `--style` 且对话/原件中无明确说明），Agent 必须先参照[视觉画风库](style-presets.md)向用户提问选择内置画风或自定义画风，再把确认后的画风锁定到专属技能与制作数据中。** 脚本不复制公共 `tools/studio` 代码、参考文档或整套素材；重复运行保留现有内容。已有自定义AGENTS时由Agent合并入口，不覆盖其原有指令。

续作先定位作品目录并读项目AGENTS、主技能和专属技能，再读本次原件、最新修订和当前集制作数据。从工作区根目录处理项目也必须执行这一路由，不依赖子目录指令自动注入。项目目录和入口即为索引，不另建注册表。未指定作品且无法从原件判断时，先利用已有信息定位，再只询问必要的归属。

## 专属技能保存什么

- **视觉画风锁（`style_name` + `style`）：** 保存本剧经用户确认的画风预设（S1–S6 之一）或自定义画风定义（渲染媒介、线条/体块、光影对比与色彩倾向），以及提示词头部使用的 ≤25 字精炼质感短语，确保整季人物与场景媒介统一。
- **题材与情绪承诺：** 主副题材、核心冲突与观看期待、主要情绪、爆点兑现方式，以及本剧容易失真的倾向。写对本剧有效的选择，不复制通用戏剧理论。
- **导演执行方法：** 主摄影倾向及适用原因；构图、人物调度、摄影距离、运动、剪辑、声音怎样实现本剧情绪。必要时注明动作戏／关系戏／悬疑段的不同拍法与适用边界，不堆导演姓名。风格参考链接可保留，已选定方法不逐镜联网重查。
- **连续性依据与改编边界：** 指向现有原件、人物／场景设定、世界观及当前制作数据的真实路径；记录跨集有效的用户选择和已授权改编范围。已有设定文件用路径引用，不再抄写一份。没有独立设定文件时，少量稳定设定直接写入专属技能。

从原件提取的事实、用户明确确认的选择、Agent推定的拍法分别表明依据。推定不得冒充用户确认；不确定的剧情事实放当前制作数据pending_items，不写成长期定论。来源链接相对当前SKILL.md所在目录计算，写入后确认文件存在。技能不保存逐镜剧本、完整提示词、素材状态、任务队列、密钥、修改日志或审阅分数。

## 生效与更新

用户最新指令及当前原件/已授权改编范围优先。专属技能细化题材与拍法，未明确另改的公共时长、画风、参考图及提交规则仍按主技能；不能把自动匹配导演解释成用户授权改剧情或付费生成。

提示词编写统一执行主技能的八条创作约束与[当次模型规范](model-routing.md)，默认Wan3每次30秒主生成，用户提出后才处理H3局部补镜，Seedance2.5保留为复杂打斗特效候选。专属技能提供人物、场景、连续性和导演设计依据，将当前镜头需要的内容转成完整正向描述；能力跨集重复使用时可记录其稳定的特效造型、材质、运动和光影特征，逐镜触发与规模仍放制作数据。切换模型不复制项目技能，也不自动生成三套正文。

专属技能记录跨集方法；每集制作数据的director_style记录本集实际采用的方法及必要例外，具体镜头、提示词仍以本集生效数据为准。两者不一致时查用户最新修订，不静默选一份覆盖另一份。既有剧集尚无专属技能时，从其已确认内容补建，不为了归类倒改旧稿。

临时场景拍法只写当前分镜；作品整体风格、题材定位或长期设定变化才更新专属技能。另一部作品即使题材相同也使用独立专属技能，不继承前作角色与世界观。只有用户确实要独立改编版本时才分目录建版本，不按导演名或每集复制技能。

主技能升级只更新公共入口，项目下次创作读其现行版本，不批量覆写专属技能。专属风格变更也不自动重写已批准剧集或历史视频：本次受影响稿直接修改并按原有一轮审阅流程处理，不加专属技能审批、同步报告或额外台账。现有提交快照保持原样。
