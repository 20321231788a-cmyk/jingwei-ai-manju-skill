## 💡 核心理念：用户只给原件，AI 跑完百条导演与机检规则

很多 AI 漫剧烧钱抽卡却依然“人设像证件照、背景像游客照、视频站桩念经、打戏融成残影”，根源在于：
1. **死守原件水词**：不敢砍废话、不把危机前置到前 3 秒，照抄小说导致划走率爆表；
2. **微表情陷阱**：低预算下让 AI 演“眼神微冷、手指轻攥”，抽卡 10 次也是面瘫站桩；
3. **打戏喂撑与越轴**：在一镜里写“拳脚如雨、连招十余招”，视频模型必出多手多脚与左右乱跳；
4. **生图缺电影美术指导 & 切模型失真**：人设用平光棚把立体感打平、背景要求全屏死锐拍出“游客照”，且切模型后丢动作与金句。

**「经纬AI，一键漫剧创作skill」（V3.6）通过「一层共用爽剧母本 + 电影级生图美学配方 + 前置画风锁 + 三大打戏引擎 + 三套模型减脂编译器 + 代码级双八门禁 + 多版本分组交互式终审看板」，兼顾审美质感与高稳出片率，同时彻底清理旧接口历史包袱与额外后置图片缩放步骤。**（内部技能目录名保留 `h3-storyboard-director` 以兼容既有项目引用）

## 🔥 二、爽剧爆点引擎与低成本外化动作红线

1. **解除原件逐字死锁（默认商业短剧提纯）**：
   - 在守住核心主线、人设底色与最终胜负的前提下，自动删减客套寒暄、压缩铺垫，将危机或羞辱前置到 **前 3 秒**（若需一字不改原文，显式设置 `"strict_verbatim": true` 即可）。
   - 冲突对白强制按 **① 挑衅/逼迫 → ② 加码/亮底牌 → ③ 一锤定音反杀** 组织，每段提炼 **1 句 ≤12 字的短视频重锤金句**。
2. **必填爆点硬槽位**：
   - 集级 `thrill_plan`：`opening_hook_3s`（前3秒痛点钩）、`core_pain_point`（核心受压点）、`payoff_climax`（宣泄反杀爆点 + `thrill_level` 1–10）、`slice_highlight`（10–15秒切片名场面与重锤金句）、`ending_hook`（集尾断钩）。
   - 段级 `dramatic_arc`：`施压/蓄势拍 → 加码/极限拍 → 爆发反杀/悬念卡断拍`。
3. **低预算高出片率：外化大动作替代细腻微表情**：
   - ❌ 严禁作为主戏剧动作：`眼神微冷`、`嘴角微动`、`手指轻攥`、`原地站桩慢聊`、`无事匀速慢推`。
   - ✅ 强制外化为 AI 一次出片即可读的动作：`猛拍木桌震飞纸符`、`探身指鼻极近景逼视`、`闪电扣腕/拎领`、`一击震退/跌坐仰望`、`大反差景别硬切`、`冷暖光效骤变`。

## ✨ 四、V3.6 新增亮点：多版本分组交互看板 + 电影级生图美学

### 1. 多版本分组交互看板与审核体验升级（`build_board.py` + `episode-board.html`）
- **合并版 / 原版单入口清洁切换**：当同一集同时包含合并版（如 30 秒合并版）与原版分镜时，头部只保留单一分组跳转按钮，杜绝多段重复标签刷屏。
- **单镜分组视图隔离**：单镜浏览模式下只显示当前版本分组的导航与镜头，一键切版本自动切换分组导航条与顶部操作工具；切换至「展开全部」可同屏总览全集，继续配合原地高清灯箱、`←/→` 切镜、单镜审阅标星与一键复制提示词使用。

### 2. 电影级生图美学引擎（从源头告别平光证件照与游客照）
- **人物四视角设定（`delivery.md` + `style-presets.md`）**：固定干净低饱和浅色棚底衬托立体轮廓，禁用发灰平光；强制 **45° 柔和塑形主光 + 发丝/肩线轮廓逆光 + 通透双点眼神光**，每套衣装写清 2–3 种材质对比与视觉记忆点，配角/中老年保留真实骨相的同时去土气、去廉价塑料感。
- **无人物电影静帧场景**：摒弃“平视游客照 / 售楼处效果图”与全屏同等死锐碎噪点，改用 **35mm/50mm 光学景深 + 极前景微虚化框景 + 60-30-10 冷暖色彩脚本 + 年代包浆置景陈设**（招牌/幌幡强制手写毛笔书法质感），直接套用 `S1–S6` 专属生图美学配方。
- **轻量原则**：直接优化提示词美学源头，**剔除额外后置放大流程与繁琐卡点**，原有看图确认保持高效轻量。

### 3. 三大打戏引擎与防崩策略（`action-vfx.md` + `build_board.py`）

针对 AI 视频模型对连续高速搏击易穿模的物理特性，内置三套高出片率打戏引擎与四道代码级防崩拦截：

| 引擎代号 (`combat_mode`) | 适用打戏类型 | 防崩核心策略（低成本少抽卡一次过） |
| --- | --- | --- |
| **`melee`** | 近身格斗 / 冷兵器拆招 | 严禁“拳脚如雨/连招十余”，拆为**单次硬碰 + 顿帧火星 + 撞碎木桌墙柱等场景破坏** |
| **`vfx_duel`** | 仙侠术法 / 异能对轰 | 单镜限 **2 层主特效**（1主形制+1环境受光），写清剑气/符环轮廓，**禁白光糊脸与对波僵持** |
| **`boss_crowd`** | 巨物压迫 / 以一敌多 | 极低角度仰拍+渺小剪影衬托体量；群战严禁写5人以上独立招式，强制**中心爆发+外围统一放射状掀飞** |

- **顿帧感（Hit-stop）+ 四层战斗音效**：命中瞬间强制写明“接触短暂停顿压实 + 火星/气浪炸开 + 短促微震回稳 + 撞物破坏”，音效落到**起势破风 → 接触爆裂 → 环境破坏 → 余波死寂接金句**四层（禁写“激烈打斗声”）。
- **分模型打斗回合上限**：`Wan3.0 (30s)` 硬限 3–4 个回合、最多 7 镜；`SD2.0 (15s)` 硬限 1–2 个回合、最多 4 镜；`H3` 专注 1 个核心接触点。

### 4. 本地可视制作工作台同步打包（`tools/studio/`）
- **真接口配置与向上游拉取模型**：接口配置面板精简为「名称 / 接口地址 / 模型 / 分辨率」，移除冗余协议下拉框并根据上游地址自动匹配适配策略；支持点击直接向上游拉取可用模型列表，已保存接口支持一键删除。
- **密钥加密持久化保存**：支持直接填入接口密钥并持久保存（Windows 下使用 DPAPI 本机加密落盘），替代旧的临时内存存储机制。
- **剧本页直达提交与全流程闭环**：剧本区新增 **「提交本分镜生成」** 与 **「提交本集生成」** 双按钮，并与资产图核对、视频版本播放标星、混剪时间轴拼接及 `.srt` 字幕一键导出打通，支持 `requirements.txt`（`requests` / `Pillow` / `imageio-ffmpeg`）本地一键启动。

## 🛡️ 五、八道代码级机检门禁（4 道反平淡 + 4 道打戏防崩）

不同于只靠文字提醒的纯 Prompt 技能，本技能内置 Python 标准库校验器，联审与导出时**自动执行代码级硬拦截**：

**A. 反平淡四道一票否决：**
1. **跨模型爆点与金句丢失拦截**：自动提取 `thrill_plan.slice_highlight` 中的引号金句，核验其是否 100% 落在当前激活模型（Wan3 / SD2.0 / H3）的生效提示词中；
2. **提示词头部肥胖拦截**：自动计算第一镜时间戳之前的头部字数（Wan3 > 110 字、SD2.0 > 95 字直接拦截）；
3. **单段台词过载拦截**：校验 SD2.0（>38 字）与 Wan3（>85 字）台词密度，防止塞满长台词变成站桩念经；
4. **微表情站桩词拦截**：扫描动作描述，发现只有“眼神微、嘴角微、手指轻”等弱动作且无强外化动词时直接打回重写；并校验 `dramatic_arc` 三拍弧线。

**B. 打戏专项四道防崩拦截（单元设置 `combat_mode` / `is_combat` 时自动触发）：**
5. **攻防轴线与持械锁校验**：未填 `combat_axis` 或未写明初始画左/画右站位直接报错，换位必须全景显式跨线；
6. **高危崩坏词拦截**：自动拦截 AI 必糊词汇（如`拳影如雨`、`连招十余`、`连续格挡多次`、`万道金光淹没`、`激烈打斗声`）；
7. **防喂撑镜头密度拦截**：打戏段 SD2.0（15s）超过 4 镜、Wan3.0（30s）超过 7 镜直接报错提示精简回合；
8. **受击物理反馈与战损核验**：强制正文落地具体受击结果（`震退 / 撞碎 / 火星 / 倒飞 / 裂痕 / 气浪 / 战损`等），并在看板直观展示 `⚔️ 打戏引擎` 与 `🧭 攻防轴线与持械`。

## 📦 七、快速安装（核心技能零依赖 · 附带工作台）

将技能目录置于工作区的 `.agents/skills/h3-storyboard-director`，并将仓库内的 `tools/` 目录部署到工作区根目录 `<工作区>/tools/`，即可被 **Antigravity / Codex / Claude Code** 等主流 Agent 自动挂载并配合本地工作台使用：

```powershell
# 方式一：使用 GitHub CLI 克隆仓库，并同步部署工作区 tools/
gh repo clone 20321231788a-cmyk/jingwei-ai-manju-skill .agents/skills/h3-storyboard-director
Copy-Item -Recurse -Force .agents/skills/h3-storyboard-director/tools ./tools

# 方式二：解压 V3.6 发行版压缩包并部署 tools/
Expand-Archive -Path "经纬AI-一键漫剧创作skill-V3.6.zip" -DestinationPath .agents/skills/h3-storyboard-director -Force
Copy-Item -Recurse -Force .agents/skills/h3-storyboard-director/tools ./tools
```

运行离线自检（核心技能仅依赖 Python 标准库，无需 `pip install`）：

```powershell
python .agents/skills/h3-storyboard-director/scripts/test_build_board.py -v
# Expected: Ran 15 tests ... OK
```

如需启用本地工作台提交与混剪导出，安装工作台依赖后运行单元测试或启动工作台：

```powershell

python -m unittest discover -s tools/studio -p "test_*.py"
```

## 🚀 八、三步全自动使用教程

1. **建剧并锁定画风（未指定画风时 Agent 会主动提问）**：
   - 将小说或剧本原件放入工作区，对 Agent 说：`使用 $h3-storyboard-director 帮我建新项目《作品名》并制作第1集`。
   - 若未指定画风，Agent 会展示 `S1–S6` 内置画风或自定义入口供你选择；也可以手动运行：
     ```powershell
     python .agents/skills/h3-storyboard-director/scripts/create_project_skill.py --project "作品名" --genre "题材" --style S2
     ```
2. **爽点提纯、打戏防崩编排、人设拼图与多模型编译**：
   - Agent 自动提纯 `thrill_plan` 与 `dramatic_arc`（打戏单元自动选择 `melee`/`vfx_duel`/`boss_crowd` 并锁定 `combat_axis`），分步生成人物四视角图并用 `stitch_character_sheet.py` 无损拼接为 `3344×1882` 整图；
   - 默认按 `Wan3.0`（30秒）生成高冲击提示词，也可随时指定切换 `SD2.0`（15秒）或 `H3`（短补镜）。
3. **机检与看板终审**：
   ```powershell
   python .agents/skills/h3-storyboard-director/scripts/build_board.py <作品名>/<集数>/制作数据.json --final-review
   ```
   打开生成的 `打开看板.html`（或双击 `<作品名>/启动制作看板.cmd`）核对爽点骨架、三拍弧线、打戏轴线与参考图，确认无误后一键复制提示词或通过适配队列提交生成。
