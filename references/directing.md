# 原件到高爽感、强切片爆点商业漫剧分镜

本页提供爽剧爆点提纯、外化导演调度和场面设计方法。提示词编写统一执行主技能“八条创作约束”与当次模型专属高冲击模具；导演设计转写为当前分镜高浓度的正向声画描述。模型分工、时长切分与编译模具见[模型分工与时长](model-routing.md)。

## 一、默认商业爽剧提纯与冲突观看顺序

**破除“原件字面死锁”，默认开启商业短剧提纯授权：**
在不改变原件核心人物关系、能力底层规则与主线最终胜负的前提下，Agent **必须主动对平淡、啰嗦的原件进行短剧化提纯**，不再把常规爽点强化推给“待决定项”：
1. **开场3秒必给痛点/异象暴击：** 若原件开场是慢热铺垫、环境描写或日常寒暄，默认将冲突峰值、直接羞辱、生死危机或诡异视觉奇观前置到前3秒；前15秒内必须让观众看清“主角承受了什么压迫/危机、要反击谁”。
2. **砍掉水词与无效过场：** 直接删减原件中的客套寒暄、重复解释、冗长心理独白和无进展等待；心理描写一律转为可见的外化动作或一针见血的短台词（除非用户显式在制作数据设置 `"strict_verbatim": true` 要求一字不改原件引号）。
3. **仅在触及主线颠覆时留待决定：** 只有当改编需要新增原件不存在的核心人物、改变结局胜负或推翻世界观底层设定时，才放入 `pending_items`。

每场内部按**“痛点暴击 → 压迫升级 → 底牌亮出/绝地反杀 → 可见代价与震惊反应”**组织观看顺序：明确观众先看见什么刺激画面、何时听见挑衅重音、何时切给反杀动作与围观者/对手的受击反应。听者的震惊、后退或变色可与对白并行，严禁“一人站着念一句、停一秒、切另一人站着念一句”。

## 二、强制爽剧爆点骨架（`thrill_plan` 与 `dramatic_arc` 必填槽位）

为保证下限稳定、杜绝流水账，每集在 `制作数据.json` 顶层必须先锁定 `thrill_plan`（全集爽点骨架），每个生成单元（Wan3 30秒段 / SD2.0 15秒段 / H3单元）必须锁定 `dramatic_arc`（段内三拍转折）：

### 1. 集级必填 `thrill_plan` 五要素
- `opening_hook_3s`（**前3秒痛点/异象钩**）：开篇前3秒直接砸出的视觉冲击、当面羞辱、危机降临或反常画面（严禁纯风景空镜或平淡问候开场）。
- `core_pain_point`（**核心受压/痛点**）：本集直击观众情绪的不公、轻视、威胁或绝境。
- `payoff_climax`（**情绪宣泄/反杀爆点**）：主角如何当场反制（实力碾压 / 规则反杀 / 身份打脸 / 底牌掀桌），明确爽点类型与 `thrill_level`（强度1–10）。
- `slice_highlight`（**切片爆点锚点**）：指定本集最适合单独剪出10–15秒发短视频平台的**“名场面镜头 + ≤12字重锤金句”**（引号内金句必须在生效提示词中100%原样落地，切模型不得丢失）。
- `ending_hook`（**集尾断钩**）：最后3–5秒留下的更大危机、新底牌或关系骤变，驱动点击下一集。

### 2. 段级必填 `dramatic_arc`（三拍转折）
任何生成段严禁单一情绪平推到底，必须在单元字段 `dramatic_arc` 中写明本段的三拍弧线：
- **施压/蓄势拍 → 加码/逼入极限拍 → 爆发反杀/悬念卡断拍**（例如：`"大姨拍桌指鼻逼退钱 → 掀出肩后偷笑瘦诡 → 林昊揣囊反赌双倍立威"`）。

## 三、主动设计表演与镜头：低成本高出片率的外化动作红线

在低资金投入、不靠海量抽卡筛微表情的生产条件下，**AI视频模型对“内敛微表情、克制停顿”的表现力极弱，极易生成呆板站桩画面**。编写分镜与模型正文前，必须执行以下**外化替换红线**：

| 戏剧节点 | ❌ 严禁充当主戏剧动作（AI演不出、必平淡） | ✅ 强制外化为高出片率大动态与强构图（一次生成即有张力） |
| --- | --- | --- |
| **挑衅 / 受压拍** | 眼神微冷、眉头微蹙、轻声嘲讽、站在原地对话 | **肢体侵入与物理震动**：猛拍桌面震翻茶盏/纸符、探身指鼻逼到极近景、高位俯视踩踏/逼退半步、当面撕毁/摔碎信物、多人围堵压迫构图 |
| **蓄势 / 认知突变** | 手指轻轻攥紧裙摆、目光微闪、沉默不动 | **强生理反应与光影突变**：瞳孔骤缩伴随身体猛然绷直/拍案而起、一把按住刀柄/法器、腕间契印或法器骤然爆起强光将面部染成高反差冷暖光 |
| **反杀 / 爽点爆发** | 淡淡一笑、平静说完长句、温和挥手 | **瞬时控制与力量碾压**：闪电出手扣住手腕/拎起衣领、一击震飞或气浪掀翻器物、跨步逼近迫使对手踉跄跌坐仰望、全场围观者同步骇然后退死寂 |
| **镜头切换冲击** | 无事发生的慢推、全程固定中景来回切大头 | **大反差景别硬切与动势接力**：拍桌/亮底牌极特写 → 顺手势急速上摇或同轴硬切低角度广角仰拍（放大气场碾压）；受击瞬间硬切对手失衡跌退 |

把情绪100%落到**“大幅度肢体动作 + 景别高低落差 + 物体/光影物理反馈 + 语气重音陡变”**上。联审时若把台词静音，仅凭画面动作看不出“谁在压迫谁、谁反杀了谁”，该镜直接判为平淡不合格，必须重加外化肢体压迫或物理反馈。

## 四、对白与画面：高张力三段式交锋与12字重锤金句

融合 `DialogueForge` 三段递进法则，杜绝啰嗦长句和客套废话：

1. **三段式对白升级结构：**
   - **第一轮（挑衅/逼迫）**：对手直接亮出羞辱条件、威胁或质疑，不绕弯子；
   - **第二轮（加压/亮底牌）**：矛盾推至顶点，亮出证据、代价或生死赌注；
   - **第三轮（绝地反杀/立威）**：主角用极短狠话或反常行动一锤定音，直接逆转地位。
2. **台词脱水与12字重锤金句：**
   - 砍掉所有“你听我解释”“怎么会这样”“其实事情是这样的”等过渡水词。
   - **单句连续发声原则上不超过18–22字**；原件超长独白必须拆短或转为画面行动。
   - 每个核心冲突段必须设计 **1句 ≤12字、节奏铿锵、可单独做短视频醒目大字幕的“重锤金句”**（如*“这命我收了，阎王也得排队！”*、*“欺堂越界，拿散魂香抽三鞭！”*），并在金句落点同步绑定最强动作或特效峰值。

### 情绪语速与台词内镜头时序

先确定一句话以什么情绪极值（暴怒抢白、冷笑压迫、咬牙一字一顿）说，再估算发声时长，最后把外化动作与切镜嵌进这段时间。严禁按统一字速平读，也严禁先把镜头均分再把长台词硬塞进去。

- **单段台词容量红线：** 15秒生成段（SD2.0）总台词**严禁超过38字**（最多2–3句短狠交锋，留足5秒给纯动作与物理反馈）；30秒生成段（Wan3）总台词**控制在85字以内**。
- **跨机位同句连续：** 一句台词跨两个机位时，只有一次连续发声过程，整句只列一次。用正在说到的**关键词重音**触发切镜、运镜和听者骇然/受压反应（如*“说到‘脏东西’三字时，机位猛然退开露出她左肩后咧嘴偷笑的青白瘦脸”*），后镜从当前词句接续，不重复起念。

## 五、风格匹配：为爽感与压迫感服务

参考[全球名导演视觉风格图鉴](https://xwen111.github.io/film-style-reference/)时，匹配顺序严格服从**“本场要引爆的爽感/压迫感 → 高对比构图与快节奏剪辑 → 适用视觉参考”**。将本剧采用的拍法写入[项目专属技能](project-skills.md)与每集 `director_style`。严禁为了模仿文艺片风格而加入展示性空镜、无目的慢推或沉闷停顿；一切构图（高低位权力对比、前景遮挡突袭、广角仰拍立威）必须直接放大冲突与爽点。

## 六、空间与摄影：防越轴且不写静态说明书

编写前打开绑定场景底图核对门、桌、椅、通道的实际左右与数量；底图椅位会诱导错误分座时先修底图或锁死空椅。每个镜头写明人物在当前景框的绝对屏幕位置（画左/画中/画右/前景/背景）与朝向（面向画左/画右），但**必须将方位词直接融进强动作主谓宾句中**（如*“画左大姨左手把红布锦囊狠拍在桌心，指着画右跷腿赔笑的林昊怒骂”*），严禁在镜头开头单独罗列一段静态位置说明书消耗模型注意力。

切镜由暴击动作、亮底牌或激烈反应触发，优先采用**动中硬切（Action Match Cut）**：切前写明动作已到哪一阶段（如抬臂挥落、踏前一步），切后从同一相位紧接命中与受击反馈，绝不重复起手、重复命中或打完归零。

## 七、时长与多模型节拍装填

区分摄影镜头、剧情分镜和生成请求，按[模型分工与时长](model-routing.md)装填高能节拍：
- **Wan3.0（30秒主生成）**：1条30秒承载完整的**「0–8s痛点暴击 → 8–18s施压极限 → 18–30s骤切反杀+金句+尾钩」**三拍闭环；段内包含3–5个大反差景别切镜，**第15–20秒之间强制设置一次景别大跳切+爆发动作**，杜绝后半程泄力站桩。
- **Seedance 2.0 / SD2.0（15秒生成）**：1条30秒精准拆为**前15秒（蓄压断钩段：卡在反击起手前一瞬）**与**后15秒（宣泄反杀段：硬切出手+重锤金句+死寂余波）**；单条2–3个镜头靠动势接力串联，绝不把30秒剧情平摊塞进15秒。
- **H3（4–15秒短补镜/双15秒包）**：直接截取母本中对应的核心动作爆破区间，前3字段锁死身份材质，`detailed_description` 全用高爆发英文强动词。

## 八、方法来源与范围

融合 [short-drama-factory 戏剧工艺与冲突形态](https://github.com/lixiaoxiao9888-create/short-drama-factory) 与商业爽剧爆点引擎（`thrill-drama-writer` 的开场钩、三段式挑衅反杀对话、爽点强度分级、切片金句与尾钩机制），同时**剔除其“反派无脑降智送人头”和“拆出11份独立策划文档”的冗余做法**：反派必须有真实的施压手段与压迫感，主角的反杀才更具爆发力；所有爽点规划直接作为硬字段内嵌在唯一一份 `制作数据.json` 中，由 `build_board.py` 自动校验。
