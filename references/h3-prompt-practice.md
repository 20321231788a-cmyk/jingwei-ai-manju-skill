# 编写与审核参考（含H3分支）

本页落实主技能的“八条创作约束与最终检查项目”。导演、动作、风格、连续性与声画审核各模型共用；下文H3字段、英文、Ref2VA、Shot及`<Picture N>`等格式专述只用于H3分支，不能套给Wan3。先按[模型分工与时长](model-routing.md)选定当次分支：默认Wan3每次30秒，用户明确提出处理瑕疵后才开始H3短补镜；Wan3引用写“图N”、镜头列实际起止时间。项目设定与导演设计提供内容依据，制作及后期信息由制作数据相应字段承载。

## 官方技能与读取顺序

本节仅在用户提出H3补镜处理后读取执行。Wan3读取[官方Prompt指南](https://help.aliyun.com/zh/model-studio/wan3-video-generation-prompt-guide)及公共[模型规则](model-routing.md)，不加载H3格式作为默认模板。

从 `$CODEX_HOME/skills/h3-prompt-writing/` 定位官方技能；未设置该环境变量时读取用户目录 `.codex/skills/h3-prompt-writing/`。

1. 先读官方 `SKILL.md`，确定本次输入模式。
2. Ref2VA读取 `references/ref-en.txt` 及其引用的 `references/base-en.txt`；T2VA、I2VA、FL2VA、L2VA读取 `references/base-en.txt`。
3. 严格采用对应官方指南的完整结构、字段与顺序、引用及保留关系、Shot与切点、说话人和对白标签、声音分层及语言规范。工作台的中文镜头是模型正文的完整译文，逐镜保持相同引用、动作、切点和对白。

本机原文件缺失时从[MiniMax官方技能仓库](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing)补齐。官方技能原件独立保留，本地八条创作约束写在工作区技能中。

## 爽点骨架与外化导演设计先行

在转写任何模型提示词之前，必须先完成主技能第2项及[爽点引擎与外化导演设计](directing.md#二强制爽剧爆点骨架thrill_plan-与-dramatic_arc-必填槽位)：
1. 先锁定集级 `thrill_plan`（前3秒痛点/异象钩、核心受压痛点、情绪宣泄爆点与爽点等级、切片名场面+≤12字重锤金句、集尾断钩）及本单元的 `dramatic_arc`（三拍转折）；
2. 将所有抽象情绪和内敛微表情（“眼神微冷、手指轻颤”）强制外化为**高出片率大动态（拍案震物、指鼻逼视、扣腕拎领、一击震退）、大反差景别硬切与冷暖光效骤变**；
3. 再按当次模型的[专属高冲击编译模具](model-routing.md#三三套模型的高冲击提示词编译模具头部减脂动作优先)生成正文。

## 逐镜高浓度描述（头部减脂 · 动作优先）

### 风格描述的图片依据与头部减脂铁律

各模型的风格依据使用本镜实际绑定的人物、场景与道具图片，以及本剧在[视觉画风库与自定义画风锁](style-presets.md)中锁定的 `style_name` / `style`（支持内置6大主流画风或用户自定义画风；新建项目未指定时必须先向用户提问确认）。人物图提供本人身份、形体和表面材质，场景图提供与本剧画风一致的空间、材料与现场光影，共用透视、尺度、曝光、接触阴影与交互光。

**提示词头部减脂铁律（夺回动作注意力权重）：**
- **Wan3（30秒）**：在第一个镜头时间段（`0–`）之前的头部总体说明，**硬性控制在90–110字以内**！只写明 `30秒，16:9，[强情绪题材基调 + 本剧画风≤25字精炼短语]。图1[角色A身份衣装]，图2[角色B]，图3[实景场景与主光冷暖反差]，共用透视受光。` 严禁在头部背诵“轻微皮下散射、自然肤色变化和低对比纹理、桌脚与马扎落下接触阴影”等长篇材质论文，防止稀释后续30秒的动作权重。
- **Seedance 2.0 / SD2.0（15秒）**：头部说明**硬性控制在75–95字以内**，直接点明 `@图片N` 主体绑定、本剧画风核心短语、冷暖光反差与画左/画右初始对峙方位，立刻进入 `0–` 镜头。
- **H3 Ref2VA（4–15秒/双15秒）**：**风格与动作100%物理隔离**——按官方规则将人物下颌/眼鼻比例、本剧锁定的画风质感（如赛璐璐光影/BJD微纹理/胶片颗粒）和环境光影**全部关进 `subject_definitions`、`summary` 和 `retention_analysis` 三个字段**；`detailed_description` 开头仅用1句简短英文点明 `<Picture N>` 与共同受光，随后进入 `[Shot 1]`，**严禁在Shot镜头正文里再次出现 `porcelain skin, BJD texture, contact shadow` 等静态材质词**！

保留的是同一张脸的基础几何，高幅度表情极值（暴怒、冷笑、骇然失色）、口型、透视变化和剧情受击变形随动作自然发生。

### 实际站位并入强动作句与上下镜接续

编写前先打开本镜绑定的无人物场景底图，核对门、桌、椅、沙发、通道在图中的实际屏幕左右与数量；底图座椅摆法与剧情站位冲突时先修底图或锁死空椅归属。

**方位词直接并入强动作句（禁写独立静态说明书）：**
每个镜头必须依据固定场景物写明当前人物在景框内的绝对屏幕位置（画左/画中/画右/前中后景）与朝向（面向画左/右），但**必须将方位词直接嵌进高幅度动作的主谓宾句中**（例如：*“0–4.5秒。木桌斜侧极特写顺手势急速上摇至双人近景！画左大姨左手把红布锦囊狠拍在桌心震飞纸符，探身指着画右跷腿赔笑的林昊鼻尖怒骂”*），严禁在镜头开头花两句话静态介绍谁坐在哪张椅子上。

下一个镜头从上一个镜头留下的实际动作相位开始（动中硬切接力）。人物引用、实际出入画、身体状态和道具归属逐镜对应；上一镜留下的受击失衡、持物、战损和光效直接作为本镜入态。

### 高出片率外化动作、物理反馈与大反差摄影

本节统一执行主技能第4项。针对低资金投入、少抽卡即可稳定出片的要求，每个Shot的首句必须写明**“冲击景别/机位 + 高幅度外化动作 + 直接物理/光效反馈”**：
- **禁用平淡微表情充数**：清理“微微、轻轻、略微、眼神微凝、手指轻捻”等AI视频模型无法稳定表现的弱动作；必须落实为拍桌震物、探身逼视、扣腕拎领、挥袖震退、踉跄跌坐、器物碎裂或契印/法器骤亮染脸等强可见过程。
- **动作因果链完整**：写清触发、起势、接触受力、速度陡变、器物/布料物理反馈和终态，使上一动作的冲击结果直接触发下一镜头的反击或骇然反应。
- **大反差景别硬切与有触发运镜**：在重锤金句或出手反杀瞬间，优先使用**大反差景别硬切**（如拍桌/亮底牌极特写 → 同轴硬切低角度广角仰拍气场碾压）或顺动作方向的急速推拉摇移；严禁无事发生的匀速慢推或全程固定中景站桩对话。连续推近、摇摄仍属当前Shot，仅在实际切镜处新建Shot。
- **Wan3中段视觉唤醒与SD2.0动势接力**：Wan3的30秒段必须在第 `15–20秒` 之间安排一次景别大跳切+爆发动作唤醒后程动态；SD2.0的15秒段严格控制在2–3镜，靠镜头间的动作动势接力串联。
- **特效与光效强对比触发**：按实际效果使用自发光（emission）、辉光（bloom）、粒子拖尾、体积散射与交互光，让法相/契印亮起瞬间在人物脸部与实景物面上打出强冷暖反差，同时严禁满屏白光吞没打脸接触点。

### 按当前声画顺序组织文字与三段式脱水台词

逐镜沿实际播放顺序写当前冲击构图、外化动作、物理声响，随后紧贴触发点切入脱水短台词，不先放整段对白再补写画面。
- **台词脱水与金句绑定**：冲突对白按 **① 挑衅/逼迫 → ② 加压/亮底牌 → ③ 一锤定音反杀（含≤12字重锤金句）** 组织；SD2.0（15秒）单段总台词 **≤38字**，Wan3（30秒）单段总台词 **≤85字**，单句连续发声原则上不超过18–22字。
- **跨切同句连续**：一句台词跨机位时只列一次完整原话，用关键词重音触发景别硬切与听者受压/震惊反应。

### 当前分镜的高浓度正向描述

提示词只保留当前单元高浓度的正向动态画面、声音与官方引用；清除负面排除句、历史改稿解释、编写意图词（如“明确建立视线”“体现压迫感”）和冗余材质套话。

## 官方对照审核（含「平淡度一票否决」四条硬门禁）

在现有一轮联审中，**先执行「平淡度一票否决」四条硬门禁（任一条不达标立即打回重写），再按主技能八项逐镜核对并直接修回同一份制作数据**：

### 【平淡度一票否决清单】
1. **前3秒生死线否决：** 检查全集第1段前3秒及每段起手——凡是纯风景空镜、缓慢推镜、日常寒暄问候开场，直接一票否决！必须改为痛点羞辱、危机降临、器物拍碎或诡异视觉奇观起手。
2. **静音站桩否决（微表情拦截）：** 假想把所有台词静音，只看镜头动作描述——如果看不出“谁在压迫谁、谁反杀了谁”，或者主动作全是“微微蹙眉、轻轻低头、站在原地说话”，直接一票否决！必须替换为高幅度外化动作、物理震动与大反差景别硬切。
3. **头部肥胖与台词念经否决：** 检查Wan3（头部≤90–110字、单段台词≤85字）、SD2.0（头部≤75–95字、单段台词≤38字）、H3（`detailed_description`零静态材质套话）及单句长度（≤18–22字）——凡是头部塞满材质说明书或台词从头念到尾导致画面无呼吸区的，直接一票否决！
4. **切片金句与跨模型丢爆点否决：** 检查顶层 `thrill_plan.slice_highlight` 中的 **≤12字重锤金句** 与核心反杀动作是否100%原样出现在当前激活模型（Wan3 / SD2.0 / H3）的生效提示词中——切换模型时若金句或爆点丢失，直接一票否决！

### 【八项统一核对】
1. **官方规范、模型专属模具与时长法则。** 核对当次模型及真实适配能力：Wan3固定30秒（三拍闭环+第15–20秒视觉唤醒，“图N”与上传顺序一致）；SD2.0固定15秒（蓄压断钩段/宣泄反杀段对拆，2–3镜动势接力，“@图片N”一致）；H3核对替换范围、短时长及完整六字段与 `<Picture N>` 标签。模型转换不丢金句、切点、外化动作或特效。
2. **爽点骨架与外化导演设计。** 核对顶层 `thrill_plan` 五要素与每段 `dramatic_arc` 三拍弧线已完整填写且落地到镜头正文；开场3秒钩、施压升级、反杀爆点与尾钩具有明确的外化大动作、高低位构图与大反差景别切镜，未退化为微表情或抽象情绪词。
3. **位置并入动作与人物连续。** 对照场景底图、上镜出态和本镜入态，核对画左/画右方位词已直接融进强动作句中，人物朝向、持物、进出画与跨段首尾动势接点严丝合缝，四视角整图未转写成多人。
4. **动作高爆发、物理反馈与摄影完整。** 逐句审读中文分镜与当次模型实际提交提示词，确认首句以“冲击景别+外化强动作+物理/光效反馈”领头；清理编写意图与微表情弱词；动中切镜继承同一动作相位，未重复起手或重复命中；特效轮廓、材质、亮核与交互光清楚，未用满屏白光吞没接触点。
5. **高浓度正向且仅限当前分镜。** 模型字段只保留当前镜头的高浓度正向动态描述和官方引用；清理负面排除、无关事项与冗余材质防腐剂。
6. **风格与身份引用极简精准。** 人物、环境及表面风格各有已绑定图片依据，图序一致；Wan3/SD2.0头部风格绑定精炼不超字数，H3风格材质锁死在前三字段；共同表面风格不改变本人骨相与眼鼻口比例。
7. **三段式脱水台词、12字金句与同句声画连续。** 核对冲突台词已脱水为“挑衅→加压→反杀+≤12字重锤金句”（除非显式开启 `strict_verbatim: true`），单段总字数与单句长度不超标；逐句情绪极值、重音与发声区间相容，跨机位同句只列一次，用关键词重音触发切镜与听者反应。
8. **一句话拍法概述与三拍爆点展示。** 联审后核对看板的 `directing_summary` 与 `dramatic_arc`，以人名和强动词按顺序概括三拍动作、景别硬切、重锤金句与结果，每项均在生效正文中100%对应。

结构检查辅助核对字段、文件、标签和时间；视频生成后，人物出场、实际位置、动作与声画效果通过播放成片核验。特效还须对照[美术设计检查](action-vfx.md#统一审阅时检查)核对轮廓、材质、明暗与疏密主次、运动节奏和人物可读性；不能只检查是否出现。指出Wan3成片问题不自动进入H3处理或付费抽卡。
